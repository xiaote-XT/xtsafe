# 星特安全 (XT Safe)

> 锁机反制 · 恶意软件禁止安装 · 无障碍管理 · 应用安全扫描

星特安全是一款聚合型 Android 安全工具，提供锁机反制（防被恶意锁机）、病毒应用拦截、无障碍服务精细管理、应用安全扫描、紧急操作等多种防护能力。它不是某一特定人群的专属工具，任何人都可以使用。

## 功能特性

### 反锁机（强制置顶）
防止恶意应用关闭星特安全的无障碍服务并将你锁机。支持三种置顶模式：

| 模式 | 说明 |
|------|------|
| 重启服务 | 移除→加回无障碍服务，触发重新绑定（默认） |
| 最高优先级 | 定期重建悬浮窗，确保悬浮按钮始终位于最顶层 |
| 混合模式 | 两者同时执行，双重保障 |

- 强制置顶循环定时巡检，熄屏自动跳过、亮屏自动恢复
- 兜底闹钟独立于服务进程调度，服务被强杀后也能恢复
- 智能识别"诱导开启权限"的木马话术，顶部红条提示唤起卸载
- 连续按音量下键 10 次（3 秒内）快速唤起卸载列表

### 主动防护
- **禁止安装病毒应用**：检测到病毒包名安装时，自动通过管理员/Shizuku 禁用或卸载
- **安装病毒通知提醒**：病毒应用安装时发送通知询问是否卸载
- **唤起列表时强制停止病毒应用**：打开卸载列表时自动强制停止
- **新安装应用提示是否管控**：新应用安装时询问是否加入管控
- **智能识别风险文字**：模糊匹配诱导开启权限的木马话术并提醒
- **自定义病毒包名**：逗号分隔，与内置 35+ 恶意包名列表合并

### 音量防护
- **防音量恶意修改**：音量超过阈值时自动调为 0
- **音量最高唤起卸载列表**：音量超阈值自动弹出卸载列表
- **音量超阈值强制停止所有应用**：立即强制停止所有第三方应用
- 实时监听音量变化（非纯轮询），退到后台也能及时响应
- 阈值可调（默认 80%）

### 无障碍管理
对已注册无障碍服务的应用进行精细管理（支持批量操作）：

| 模式 | 行为 |
|------|------|
| 禁止（强制拒绝） | 关闭无障碍，持续阻止 |
| 允许（自动保活） | 保持开启，被关闭时自动恢复 |
| 10 分钟内允许 | 临时放行，超时自动关闭 |
| 锁屏后禁止 | 锁屏后立即关闭 |
| 智能管理 | 进入银行/支付等敏感 App 时自动关闭，离开后恢复；锁屏关闭，亮屏询问是否恢复（5 秒无操作自动恢复） |

### 管控列表
- 管控应用不禁止安装，仅统一管理
- 卸载列表中蓝色标记，可单独筛选
- 长按移除，支持手动新增
- 被管控应用默认设为智能管理模式

### 敏感 App 管理
- 内置 55+ 个银行/支付金融应用包名
- 支持搜索、新增自定义包名
- 长按移除（默认包名可恢复）

### 应用安全扫描
支持已安装应用扫描、手动选择 APK、接收分享/打开的 APK 文件：

- **权限组合检测**：从 Manifest 提取真实权限，匹配危险组合（如 `INTERNET + RECEIVE_SMS + SEND_SMS` 可能扣费）
- **签名 MD5 检测**：对比风险签名列表，发现篡改或滥用签名
- **风险类名检测**：识别已知恶意框架/注入类（Epic、云镜、SetupInfoActivity 等）
- **文件特征检测**：检测恶意 SDK 文件特征
- **字符串特征检测**：扫描 DEX 敏感特征（无障碍强制启用、屏幕录制、远程命令、静默安装卸载等），每条特征可独立配置风险等级
- **病毒包名检测**：匹配内置恶意包名列表，直接标记
- **白名单机制**：包名 + 签名 MD5 双重匹配，完全匹配跳过扫描；签名异常标记"疑似被修改"
- **名称/包名校验**：防仿冒名（如应用名含"我的世界"但包名非官方 → 最高风险）
- **方法级确认 API**：遍历 DEX 指令确认敏感 API 真实被调用（降低误报）
- **自动检测新安装应用**：新应用安装自动扫描，静音通知不打扰，有风险时提醒

### 规则管理
三源独立存储，后加载覆盖先加载：
- **内置规则**：`assets/scan_rules.json`（不可删除）
- **云端规则**：`filesDir/scan_rules_cloud.json`（可删除，支持云端自动更新，每天/每周/每次打开）
- **导入规则**：`filesDir/scan_rules_imported.json`（可删除，支持文件/链接导入）

### 紧急操作
在卸载列表顶部点击"紧急操作"，可执行：
- 强制停止所有非系统应用
- 关闭除本应用外的所有无障碍服务
- 关闭所有应用管理员权限
- 关闭/重设锁屏密码
- 占满内存（让系统停止所有应用）

均需二次确认，防止误触。

### 应急键盘
锁机时的备用方案（系统输入法）：
- 原生样式控件 + 深色背景
- "关闭所有无障碍" / "强制停止所有应用" 两个紧急按钮
- 二次确认完全在键盘内完成，不依赖系统弹窗

## 快速开始

1. 安装并打开星特安全
2. 授予三项关键权限：
   - **无障碍服务**（核心，反锁机/卸载列表必需）
   - **Shizuku**（静默卸载、强制停止等 Shell 操作）
   - **设备管理员**（防卸载）
3. 在"悬浮反锁机设置"中选择置顶模式（推荐混合模式）
4. 开启"主动防护"中的各项开关

## 权限说明

| 权限 | 用途 |
|------|------|
| 无障碍服务 | 反锁机、卸载列表、无障碍管理、风险话术识别 |

| 设备管理员 | 防卸载、强制锁屏、清除数据 |

| 通知 | 安装提醒、扫描结果、规则更新 |
| 开机自启动 | 开机自动恢复无障碍并调度兜底闹钟 |
| 应用使用情况 | 可选，用于统计 |

## 使用须知

1. 安全防护工具不是万能的，**只防意外，不防瞎操作**
2. 禁止安装功能可能无法拦截应用商店安装的
3. 密码千万不要忘记！否则可能难以卸载星特安全，建议记在纸上
4. 不要乱设置，不懂的保持默认即可
5. 不要给除 Shizuku 和星特安全以外的软件无线调试权限，否则防护会失效
6. 敏感 App 列表建议自己补充微信、QQ、美团等涉及交易的软件
